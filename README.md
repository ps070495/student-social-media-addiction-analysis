# Student Social Media Addiction Analysis — Power BI Dashboard

An interactive Power BI dashboard analyzing how social media usage affects
students' academic performance, mental health, sleep, and relationships.

## Project Overview
This project explores digital behavior patterns among students aged 18–24
across multiple countries and academic levels, using metrics like average
daily usage, addiction score, sleep hours, mental health score, and
conflict/relationship data.

## Dashboard Pages
1. **Executive Overview** – Key KPIs: total students, average usage,
   average sleep hours, % academically affected, addiction score by
   academic level, gender split.
2. **Academic Impact** – Daily usage vs. academic level, platform-wise
   impact on academic performance.
3. **Mental Health & Lifestyle** – Sleep hours vs. age, country-wise
   mental health band comparison.
4. **Relationships & Conflicts** – Conflict level by relationship status,
   student-wise addiction scores.
5. **Social Media by Academic Level** – Usage hours and platform
   preference across academic levels.
6. **Social Media by Gender** – Usage hours and platform preference by
   gender.
7. **Student Profile (Drill-through)** – Individual student-level detail
   view: demographics, digital behavior, and social metrics.

## Tools Used
- Power BI Desktop
- DAX (calculated measures/columns)
- Data cleaning & transformation (Power Query)

## Repository Structure
See folder structure in this repo — `powerbi/` contains the `.pbix` file,

## Key Insights
- Undergraduate students report the highest average daily usage.
- Instagram and TikTok are the most-used platforms overall.
- Higher addiction scores correlate with lower sleep hours.
- "Single" and "In Relationship" students show the widest range in
   conflict levels.
